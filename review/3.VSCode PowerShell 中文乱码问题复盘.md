# VSCode PowerShell 中文乱码问题复盘

## 一、问题现象

在 VSCode 集成终端中运行 IMGM 后，Electron/Node.js 输出的中文变成乱码，例如：

```text
buildFallbackIntent result: { shouldSearch: false, query: '浣犲ソ' }
```

其中 `浣犲ソ` 实际对应中文 `你好`。

同时终端中出现了：

```text
libpng warning: iCCP: known incorrect sRGB profile
```

## 二、原因分析

### 1. PowerShell 使用了旧代码页

通过以下命令检查终端编码：

```powershell
chcp
$PSVersionTable.PSVersion
```

当时得到的结果为：

```text
活动代码页: 936
PowerShell 5.1
```

代码页 936 对应 GB2312/简体中文代码页，而 Node.js/Electron 的日志使用 UTF-8 输出。UTF-8 字节被终端按 GB2312 解析后，就会出现 `浣犲ソ` 这类乱码。

PowerShell 5.1 版本本身不是中文乱码的直接原因，但它的 UTF-8 和原生程序输出处理方式比较旧，在 VSCode 集成终端中更容易遇到代码页问题。

### 2. `notepad $PROFILE` 不会自动修改编码

执行：

```powershell
notepad $PROFILE
```

只是打开 PowerShell 配置文件，并不会自动写入编码配置。还需要手动把配置内容粘贴进去、保存文件，并重新加载配置或重启终端。

### 3. libpng 警告与中文乱码无关

`libpng warning: iCCP: known incorrect sRGB profile` 表示某张图片内嵌的 sRGB/ICC 颜色配置文件不规范，通常不会影响图片读取和功能运行。它属于图片元数据警告，不是 PowerShell 编码错误。

## 三、临时修复方法

在启动项目的同一个 VSCode PowerShell 终端中执行：

```powershell
chcp 65001 | Out-Null

$utf8 = New-Object System.Text.UTF8Encoding($false)
[Console]::InputEncoding = $utf8
[Console]::OutputEncoding = $utf8
$OutputEncoding = $utf8
```

然后验证：

```powershell
chcp
[Console]::OutputEncoding.CodePage
$OutputEncoding.CodePage
node -e "console.log('中文测试')"
```

预期结果为：

```text
活动代码页: 65001
65001
65001
中文测试
```

## 四、永久修复方法

### 1. 打开当前 PowerShell 配置文件

```powershell
notepad $PROFILE
```

### 2. 在配置文件末尾添加

```powershell
chcp 65001 | Out-Null

$utf8 = New-Object System.Text.UTF8Encoding($false)
[Console]::InputEncoding = $utf8
[Console]::OutputEncoding = $utf8
$OutputEncoding = $utf8
```

### 3. 保存并重新加载

在当前终端执行：

```powershell
. $PROFILE
```

也可以直接关闭当前 VSCode 终端，重新创建一个 PowerShell 终端。

## 五、最终验证

重新打开 VSCode PowerShell 终端后执行：

```powershell
chcp
node -e "console.log('中文测试')"
npm start
```

确认终端显示 `65001` 和正常中文后，再运行 IMGM。最终中文日志恢复正常，说明配置生效。

## 六、后续建议

1. VSCode 中可以优先使用 PowerShell 7，UTF-8 支持通常比 Windows PowerShell 5.1 更稳定。
2. 修改 PowerShell 配置后，必须重新加载 `$PROFILE` 或重启终端。
3. `chcp 65001` 必须在运行 `npm start` 的同一个终端环境中生效。
4. VSCode 编辑器右下角的 UTF-8 文件编码设置只影响文件读写，不会自动改变集成终端代码页。
